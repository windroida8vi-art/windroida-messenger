# اپ اندروید Windroida (نسخه ۱.۴)

اپ به‌طور پیش‌فرض همون نسخه‌ی وب (WebView) رو باز می‌کنه که تست‌شده‌تره. یه رابط بومی آزمایشی (ناقص) هم داخل پروژه هست: از منوی نسخه وب، دکمه‌ی «📱 نسخه‌ی آزمایشی بومی (ناقص)». اگه کرش کنه خودش برمی‌گرده به وب، و تو خود نسخه بومی هم از منوی کناری «برگشت به نسخه قدیمی» هست. نسخه بومی فقط کامپایل و شبکه‌اش با سرور تست شده، روی گوشی نه.

## چی داره
- آیکون واقعی تو لیست برنامه‌ها، بدون نصب گواهی تو گوشی. برنامه اولین بار اثر انگشت (SHA-256) گواهی سرور رو نشون می‌ده؛ با اثری که تو پنجره `start.bat` چاپ شده مقایسه کن و «اعتماد می‌کنم» رو بزن. از اون به بعد فقط همون گواهی قبوله (اگه عوض بشه وصل نمی‌شه).
- اعلان پیام وقتی برنامه بسته/پس‌زمینه‌ست: یه سرویس پیش‌زمینه هر ۲۵ ثانیه از `POST /notify` سرور می‌پرسه (long-poll). به گوگل/FCM وابسته نیست. متن پیام و اسم فرستنده رو نشون می‌ده؛ با زدن روی اعلان همون چت باز می‌شه.
- بعد از ریستارت گوشی خودش دوباره شروع می‌شه. موقع اولین ورود از شما می‌خواد برنامه از بهینه‌سازی باتری مستثنی بشه (برای پایدار موندن اعلان لازمه).
- میکروفون/دوربین (ویس، تماس، اتاق)، انتخاب فایل برای آپلود و دانلود فایل (تو پوشه Downloads) پشتیبانی می‌شه.

## ساخت APK — راه ۱: GitHub (بدون نصب چیزی)
1. کل پوشه پروژه رو تو یه مخزن GitHub بذار (خصوصی هم می‌شه).
2. تب Actions ← «Build Windroida APK» ← Run workflow.
3. بعد از چند دقیقه، فایل `windroida-apk` رو از Artifacts دانلود کن (داخلش `app-debug.apk`) و رو گوشی نصب کن (اجازه «نصب از منبع ناشناس»).

## ساخت APK — راه ۲: Android Studio (روی کامپیوتر خودت)
1. Android Studio رو از developer.android.com/studio نصب کن (نسخه Koala یا جدیدتر). اینترنت لازمه، چون موقع اولین باز کردن چند صد مگابایت چیز دانلود می‌کنه.
2. File ← Open ← همین پوشه `android` (نه پوشه اصلی پروژه) رو انتخاب کن.
3. صبر کن «Gradle Sync» تموم بشه (پایین صفحه). اگه گفت SDK 34 نصب نیست، روی لینک «Install» بزن.
4. منو Build ← Build Bundle(s) / APK(s) ← **Build APK(s)**.
5. وقتی تموم شد بالا راست «locate» میاد؛ فایل تو `android/app/build/outputs/apk/debug/app-debug.apk` هست. رو گوشی کپی کن و نصبش کن (اجازه «نصب از منبع ناشناس»).
اگه Gradle Sync خطا داد، متن کامل خطا رو برام بفرست.

## استفاده
1. برنامه رو باز کن، آدرس سرور رو بزن: `https://your-server:8081`
2. اثر انگشت رو تأیید کن.
3. وارد حساب شو. اجازه اعلان و باتری رو بده.
4. **عوض کردن آدرس/آی‌پی سرور:** تو برنامه منو ← تنظیمات ← «🌐 آدرس سرور (اپ اندروید)». اگه سرور عوض شده باشه و صفحه باز نشه، خودش پنجره «تغییر آدرس سرور» رو نشون می‌ده. با آدرس جدید باید اثر انگشت گواهی رو دوباره تأیید کنی و دوباره وارد بشی.

## محدودیت‌های شناخته‌شده
- اگه WebSocket روی گواهی خودامضا تو WebView وصل نشد (تو بعضی نسخه‌ها پیش میاد)، بگو تا راه جایگزین بذارم.
- دانلود فایل‌های `blob:` پشتیبانی نمی‌شه.
- بدون کلید خودت، APK با کلید debug امضا می‌شه؛ برای «سپر امنیتی گوگل» بخش پایین رو ببین.

## فضای ابری و قاب داخل اپ (v2.9)
- لینک‌های «فضای ابری» و «قاب» تو صفحهٔ جدای خود اپ (`SiteActivity`) باز می‌شن، نه تو مرورگر: همون گواهی تأییدشده، همون انتخاب‌گر فایل برای آپلود.
- دانلود با خود اپ (گواهی پین‌شده + کوکی ورود) انجام می‌شه و تو `Download/Windroida` می‌شینه؛ کادر پیشرفت داخل صفحه (`window.wdDl`) نشون داده می‌شه. دانلود blob تو WebView ممکن نیست، برای همین فضای ابری تو اپ از `WD.saveFileId` استفاده می‌کنه.
- هنوز روی گوشی واقعی و با Gradle کامپایل نشده.

## سپر امنیتی گوگل (Play Protect) و امضای ثابت (v1.2)
**قول نمی‌دم هیچ‌وقت هشدار نده**؛ گوگل برنامه‌های «ناشناس» رو (سازندهٔ ثبت‌نشده، کم‌نصب) تو هر حالت یه بار نشون می‌ده. کارهایی که واقعاً هشدار و بلاک‌شدن رو کم می‌کنه:
1. **امضای ثابت با کلید خودت (مهم‌ترین):** APK دیباگ (`app-debug.apk`) بیشتر از همه بلاک می‌شه. یک بار `android/make-keystore.bat` رو بزن (کلید `windroida.jks` و رمزش رو **جای امن نگه دار و بکاپ بگیر**؛ گم بشه دیگه آپدیت روی نسخهٔ نصب‌شده ممکن نیست). بعد `gradle assembleRelease` یا Android Studio ← Build ← Generate Signed APK. با GitHub: محتوای base64 فایل `windroida.jks` رو تو Secrets به اسم `WD_KEYSTORE_B64` بذار، و `WD_KS_PASS` و `WD_KEY_ALIAS` (و در صورت فرق `WD_KEY_PASS`). همیشه با همین کلید بساز.
2. **هر نسخه همون کلید:** عوض‌کردن کلید = هشدار تازه + باید اول اپ قدیمی پاک بشه.
3. کد مبهم‌سازی (obfuscation) نمی‌شه؛ عمداً خاموشه چون خودش مشکوک‌تر نشون می‌ده.
4. **سمت گوشی:** تو پنجرهٔ هشدار «More details» ← «Install anyway»، یا «Scan app» رو بزن تا گوگل همین فایل رو بررسی کنه (اون فایل بعدش «شناخته‌شده» می‌شه). دلیل هشدارش رو بخون: اگه گفت «App blocked to protect your device» یعنی هنوز دیباگ/امضانشده‌ست.
5. رفتارهایی که اسکنرها حساس‌ترند: «بوت‌شدن خودکار + سرویس همیشه روشن + درخواست مستثنی‌شدن از باتری» (برای اعلان لازمه، پس مونده)؛ چیز پنهانی تو برنامه نیست و همهٔ کدش تو همین پوشه‌ست.
بعضی کشورها/نسخه‌های اندروید قانون «تأیید هویت سازنده» برای نصب بیرونی دارن؛ اگه تو گوشی تو لازم شد، از تنظیمات «Developer verification» گوگل پیگیری کن (من تو این جلسه چک نکردم).

## نسخه ۱.۳ (v4.5) — ظاهر native
- اسپلش native (انیمیشن حلقه‌ای، بدون سفیدی هنگام بازشدن)، صفحهٔ خطای native با «تلاش دوباره» و «تغییر آدرس سرور» و تلاش خودکار با برگشتن شبکه.
- لرزش لمسی هنگام حرکت/خوردن مهره در شطرنج، و روشن‌ماندن صفحه حین بازی.
- ⚠ این تغییرات کامپایل و روی گوشی تست نشده‌ن؛ اگه Android Studio خطا داد، متن خطا رو بفرست.
