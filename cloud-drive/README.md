# Cloud Drive — پلتفرم آپلود و مدیریت فایل (شبیه Google Drive)

اجرا روی کامپیوتر شخصی، پورت **8082**، قابل دسترسی در شبکه محلی، **بدون هیچ وابستگی به اینترنت جهانی در زمان اجرا**
(بدون CDN، بدون فونت یا اسکریپت خارجی؛ همه چیز از خود سرور سرو می‌شود).

## ۱) شروع سریع

**Windows:** Python 3.12+ را نصب کنید (هنگام نصب گزینه *Add to PATH* را بزنید) و روی `run.bat` دوبار کلیک کنید.
**Linux/Mac:** `./run.sh`

اسکریپت: venv می‌سازد ← وابستگی‌ها را نصب می‌کند ← اگر مدیر وجود نداشت از شما نام‌کاربری/رمز می‌پرسد ← سرور را بالا می‌آورد.
آدرس‌ها در خروجی چاپ می‌شود، مثلاً `http://192.168.1.100:8082` (IP واقعی را برنامه خودش پیدا می‌کند).
- کاربران: `http://IP:8082/` — پنل مدیریت: `http://IP:8082/admin`

## ۲) نصب با «اینترنت ملی» (آفلاین)
فقط ۳ بسته لازم است (`requirements.txt`). اگر `pip` به PyPI دسترسی ندارد، یکی از این راه‌ها:
1. روی هر سیستمی که دسترسی دارد: `pip download -r requirements.txt -d wheels` (برای همان نسخه Python و سیستم‌عامل مقصد)، پوشه `wheels` را کنار پروژه بگذارید. `run.bat`/`run.sh` خودکار از آن نصب می‌کنند (`--no-index`).
2. یا از هر میرور PyPI که در دسترس دارید: `pip install -i <آدرس-میرور> -r requirements.txt`.
3. `argon2-cffi` اختیاری است؛ نباشد، رمزها با scrypt (ایمن و استاندارد) هش می‌شوند. `waitress` نباشد، سرور داخلی Werkzeug استفاده می‌شود (برای استفاده جدی waitress را نصب کنید).

فونت فارسی: به‌صورت پیش‌فرض از فونت‌های سیستم (Tahoma/Segoe UI) استفاده می‌شود. برای Vazirmatn فایل `Vazirmatn.woff2` را در `app/static/fonts/` بگذارید.

## ۳) ساخت مدیر به‌روش امن
هیچ رمز پیش‌فرضی وجود ندارد. `python manage.py create-admin` (رمز مخفی پرسیده می‌شود). بازنشانی رمز: `python manage.py reset-password USERNAME`.
با Docker: `docker compose run --rm drive python manage.py create-admin`.

## ۴) پورت، شبکه محلی، Firewall، Port Forward
- پیش‌فرض `0.0.0.0:8082` (`CD_HOST`/`CD_PORT` در `.env`).
- **Firewall ویندوز** (PowerShell با دسترسی Administrator): `New-NetFirewallRule -DisplayName "CloudDrive" -Direction Inbound -Protocol TCP -LocalPort 8082 -Action Allow -Profile Private`
- Linux (ufw): `sudo ufw allow from 192.168.0.0/16 to any port 8082 proto tcp`
- **Port Forward:** در پنل مودم: TCP، پورت خارجی 8082 ← IP داخلی سیستم شما، پورت 8082. برای IP داخلی ثابت، در مودم DHCP Reservation بگیرید.
- ⚠️ با Port Forward سرویس عمومی می‌شود. قبلش: HTTPS (بخش ۵)، رمزهای قوی، `CD_COOKIE_SECURE=1`، بستن ثبت‌نام عمومی در تنظیمات پنل ادمین اگر لازم نیست، به‌روز نگه‌داشتن Python/بسته‌ها. Debug هرگز فعال نیست.

## ۵) HTTPS (Reverse Proxy)
نمونه‌ها در `deploy/Caddyfile` (گواهی خودکار) و `deploy/nginx.conf`. سپس در `.env`: `CD_COOKIE_SECURE=1` و `CD_TRUSTED_PROXY=1` (فقط پشت پراکسی خودتان). پراکسی روی 443 گوش می‌دهد و به 8082 داخلی می‌فرستد.

## ۶) پشتیبان‌گیری و بازیابی
- `python manage.py backup` ← `backups/backup-<زمان>.zip` (دیتابیس با کپی سازگار SQLite + فایل‌ها + کلید).
- بازیابی (هرگز چیزی را بازنویسی نمی‌کند): `python manage.py restore backups/X.zip مسیر_پوشه_جدید` سپس فایل‌ها را به ساختار `data/` منتقل کنید: `cloud_drive.db`، `secret.key`، و `uploads/` → `data/uploads/`، یا `CD_DATA_DIR` را روی همان پوشه (با `uploads/` داخلش) بگذارید.
- نگهداری خودکار: آپلودهای ناقص و سطل زباله منقضی هر ۱۰ دقیقه پاک‌سازی می‌شوند؛ دستی: `python manage.py maintenance`.

## ۷) تنظیمات
همه از `.env` (نمونه: `.env.example`) و پنل ادمین (نام/لوگو، حداکثر حجم، سهمیه پیش‌فرض، محدودیت نرخ، نگهداری سطل زباله، بازبودن ثبت‌نام). اسکنر بدافزار اختیاری: `CD_SCAN_COMMAND`.

## ۸) تست
`python -m unittest discover -s tests -t .` (یا `pytest`). ۵۸ تست (شامل تست نفوذ): ثبت‌نام/ورود، نقش‌ها، آپلود/دانلود، آپلود قطعه‌ای و ادامه، محدودیت حجم/سهمیه، اشتراک‌گذاری، انقضا، دسترسی غیرمجاز، پوشه‌ها، سطل زباله، سلامت API.

## ۹) رفع خطاهای رایج
- *`pip install` خطا می‌دهد:* بخش ۲ (wheels/میرور).
- *از گوشی باز نمی‌شود:* Firewall (بخش ۴)؛ هر دو دستگاه در یک شبکه باشند؛ IP درست را از خروجی برنامه بگیرید.
- *پورت 8082 اشغال است:* `CD_PORT` را عوض کنید.
- *بعد از HTTPS ورود نمی‌شود:* `CD_COOKIE_SECURE=1` فقط پشت HTTPS.
- *«نشست نامعتبر»:* صفحه را تازه کنید (توکن CSRF).
- *پیش‌نمایش PDF خالی است:* «باز کردن در تب جدید».

## ۱۰) ساختار
`app/` (API و منطق)، `app/static/` (رابط کاربران، `/admin`، صفحه لینک عمومی)، `app/storage.py` (سرویس ذخیره‌سازی مستقل؛ آماده افزودن S3)، `manage.py`، `wsgi.py`، `tests/`، `deploy/`، `data/` (دیتابیس، آپلودها، لاگ‌ها — روی دیسک، نام فیزیکی تصادفی).

## ۱۱) API (مختصر) — همه زیر `/api`
auth: `register login logout me me/password activity` · فایل‌ها: `items folders files/<id>/download|preview items/trash|restore|purge` ·
آپلود: `POST uploads` → `PUT uploads/<id>/chunks/<n>` → `POST uploads/<id>/complete` (وضعیت: `GET uploads/<id>`) ·
اشتراک: `files/<id>/shares shares public/<token>[/unlock|/download]` · ادمین: `admin/stats users files settings audit events health`.

## ۱۲) تفاوت‌ها با مشخصات اولیه (عمدی، برای کار با اینترنت ملی/آفلاین)

## ۱۳) تست نفوذ داخلی
`tests/test_pentest.py`: ورودی‌های مخرب (JSON خراب، نوع اشتباه)، ارتقای دسترسی (mass assignment)، کوکی جعلی/بازپخش‌شده، Session fixation،
CSRF، SQL injection، XSS (نام فایل، لوگو)، Path traversal، نمایش HTML/SVG، نشت اطلاعات، Brute-force (ورود، رمز لینک، تأیید مجدد ادمین)،
جعل X-Forwarded-For، درخواست حجیم، رمزهای ضعیف. آسیب‌پذیری‌های پیداشده رفع شدند و تست‌ها برای جلوگیری از بازگشت باقی ماندند.

## ۱۴) تست سنگین (Stress)
`python scripts/stress_test.py` — با سرور و دیتای موقت خودش اجرا می‌شود (به data واقعی شما دست نمی‌زند): ۲۰ کاربر هم‌زمان، رقابت روی سهمیه و روی «کامل‌کردن آپلود»،
۵۰۰۰ درخواست فاز تصادفی، فایل ۱۲۰ مگابایتی، brute-force، و در پایان بررسی سلامت SQLite، فایل‌های یتیم روی دیسک و رعایت سهمیه.

## ۱۵) نگهداری فایل‌ها و سطل زباله
- فایل‌های عادی **هرگز خودکار حذف نمی‌شوند**. فقط مواردی که کاربر به **سطل زباله** برده، **۲۰ روز** بعد از انتقال برای همیشه پاک می‌شوند (روزهای باقی‌مانده روی هر مورد نوشته می‌شود).
- تغییر مدت سطل: پنل ادمین ← تنظیمات ← «نگهداری سطل (روز)».
- اگر روزی خواستید همه فایل‌ها هم پس از مدتی پاک شوند: تنظیمات ← «حذف خودکار همه فایل‌ها پس از (روز)» (۰ = هرگز، پیش‌فرض).
- محدودیت حجم تک‌فایل نامحدود است؛ فقط سهمیه هر کاربر و فضای آزاد دیسک مانع می‌شوند.

## ۱۶) بدون محدودیت تعداد کاربر/آپلود/دانلود
- سهمیه پیش‌فرض هر کاربر **۷ گیگابایت** (افزایش برای هر کاربر: پنل ادمین ← کاربران ← ویرایش)، محدودیت حجم تک‌فایل ندارد، و محدودیت تعداد درخواست API خاموش است (۰).
- هم‌زمانی: تا ۱۰۰۰ اتصال و ۴۸ رشته (با waitress). آپلود هر چند فایل هم‌زمان ممکن است.
- حساب‌های قبلی سهمیه‌ای را دارند که هنگام ساخت داشتند: `python manage.py set-quota-all 7168` همه را روی ۷ گیگ می‌گذارد.
- محافظ‌هایی که عمداً مانده‌اند: حدس رمز (۶۰ تلاش/دقیقه برای هر IP و ۱۰ تلاش/۱۰ دقیقه برای هر نام‌کاربری)، و ۵۰ مگابایت فضای خالی دیسک برای جلوگیری از پر شدن کامل سیستم.
