🔒 رفع هشدار «اتصال خصوصی نیست»

قاب با گواهی امنیتیِ خودش کار می‌کند و مرورگر آن را نمی‌شناسد. ارتباط شما رمزنگاری‌شده است، فقط باید یک‌بار این گواهی را روی دستگاهت نصب کنی تا دیگر هشدار نبینی.

دانلود گواهی قاب

اندروید

  1. فایل را دانلود کن.
  2. تنظیمات ← امنیت ← رمزگذاری و اعتبارنامه ← نصب گواهی ← گواهی CA ← فایل را انتخاب کن.
  3. مرورگر را کامل ببند و دوباره باز کن.

آیفون / آیپد

  1. با Safari دانلود کن و «Allow» بزن.
  2. تنظیمات ← Profile Downloaded ← Install.
  3. تنظیمات ← General ← About ← Certificate Trust Settings ← «Ghab Local CA» را روشن کن.

ویندوز

  1. روی فایل دابل‌کلیک کن ← Install Certificate.
  2. Local Machine ← Place all certificates in the following store ← Trusted Root Certification Authorities.
  3. مرورگر را ببند و دوباره باز کن.

مک

  1. روی فایل دابل‌کلیک کن تا در Keychain Access باز شود.
  2. روی گواهی دابل‌کلیک ← Trust ← Always Trust.

مدیر سایت: برای حذف کامل هشدار برای همه کاربرها، یک دامنه بگیر و گواهی واقعی بگذار (راهنما در README).
